
# Suspicious Login Analyzer

## Objective
A beginner cybersecurity project for detecting repeated failed login attempts from the same IP address.

## Detection
The project identifies an IP address with multiple failed login attempts.

## Finding
IP `45.23.10.5` generated 4 failed login attempts.

## Tools
- VS Code
- Linux commands
- Log analysis
